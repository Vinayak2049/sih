A3 · Checksum decoys — look right, ARE NOT valid

Invalid Aadhaar (bad Verhoeff)1234 5678 9012
Invalid Aadhaar (starts 0)0234 5678 9013
Invalid PAN (bad 4th char)ABCXK1234F
Invalid IFSC (5th not 0)HDFC1001234

A checksum-aware detector should down-rank all of these. A regex-only one flags every single one.
